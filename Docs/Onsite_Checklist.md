### 階段一：行前準備與環境勘查

[ ] 確認現場工業網路環境（IP 位址分配、子網路遮罩、網關設定）。

[ ] 確認防火牆設定（確保 Modbus 預設通訊埠 502 沒有被阻擋）。

### 階段二：硬體與通訊驗證

[ ] 使用實體線材連接 PLC / 電表 / 流量計。

[ ] 使用 Modbus 測試工具（如 Modbus Poll）在現場直接對接設備，確認暫存器讀值正常（無 Timeout 或 CRC 錯誤）。

### 階段三：軟體部署與服務啟動

[ ] 在現場工業電腦（IPC）或主機上安裝 .NET Runtime 與 Node.js 環境。

[ ] 將後端 API 設定為 Windows 服務（Windows Service）或背景常駐執行，確保電腦開機自動啟動。

[ ] 啟動 React 前端介面或透過瀏覽器進行全螢幕展示（Kiosk Mode）。

### 階段四：系統驗收與交接

[ ] 進行 24 小時穩定度壓力測試。

[ ] 向業主/現場操作人員進行系統操作教育訓練。

[ ] 簽署專案驗收單與交付交接清單。
